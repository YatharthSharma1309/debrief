# Launch Planning — sample dataset

Upload all files in this folder into a workspace named **Launch Planning** for the Build Week demo.

| File | What it contains |
|------|------------------|
| `01-product-requirements.txt` | Product scope and goals |
| `02-pricing-notes.txt` | Pricing decision + rationale |
| `03-launch-meeting-transcript.txt` | Meeting decisions, owners, open items |
| `04-customer-feedback.txt` | Customer themes and conflicts |
| `05-launch-checklist.txt` | Dates, owners, readiness gaps |

## Demo questions

1. What decisions have already been made?
2. What did we decide about pricing and why?
3. Who owns launch readiness?
4. What is still unresolved before launch?
5. Are there conflicting dates or risks?
